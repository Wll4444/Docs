# Инструкция по установке и настройке FreeCAD Robust MCP Bridge на Windows

В данном руководстве описан процесс интеграции среды 3D-моделирования **FreeCAD** с ИИ-ассистентом **Claude Desktop** с использованием протокола **Model Context Protocol (MCP)**. Это позволяет управлять FreeCAD и создавать 3D-объекты с помощью текстовых команд на естественном языке.

---

## Шаг 1: Ручная установка верстака Robust MCP Bridge во FreeCAD

Если верстак не удается найти через стандартный встроенный *Addon Manager*, выполните ручную установку:

1. Перейдите на страницу релизов проекта: [spkane/freecad-addon-robust-mcp-server](https://github.com/spkane/freecad-addon-robust-mcp-server/releases).
2. Скачайте архив исходного кода последнего релиза: **`Source code (zip)`**.
3. Откройте директорию пользовательских дополнений FreeCAD на вашем компьютере. Для этого:
   * Нажмите комбинацию клавиш `Win + R`.
   * Вставьте путь `%APPDATA%\FreeCAD\Mod` и нажмите **Enter**.
4. Распакуйте содержимое скачанного архива в открывшуюся папку `Mod`.
5. **Важно:** Переименуйте распакованную папку так, чтобы её имя было строго **`FreecadRobustMCPBridge`** (удалите суффиксы вроде `-main` или номера версий).
6. Перезапустите FreeCAD.
7. В выпадающем списке верстаков (в верхней панели программы) выберите **Robust MCP Bridge**.
8. Нажмите кнопку **Start Bridge**. В правом нижнем углу FreeCAD должен загореться зеленый индикатор статуса: `MCP: Running (9875/9876)`.

---

## Шаг 2: Установка локального хост-сервера через Python

Для работы моста между Claude Desktop и FreeCAD необходим установленный интерпретатор Python 3.

1. Откройте командную строку Windows (`cmd`) или `PowerShell`.
2. Установите официальный пакет сервера из репозитория PyPI:
   ```bash
   pip install freecad-robust-mcp
   ```
3. Определите точный путь к установленному исполняемому файлу программы:
   ```bash
   where freecad-robust-mcp
   ```
4. Скопируйте полученный в консоли путь. Он потребуется на следующем шаге.  
   *(Примерный вид пути: `C:\Users\Имя_Пользователя\AppData\Local\Programs\Python\Python311\Scripts\freecad-mcp.exe`)*.

---

## Шаг 3: Конфигурация Claude Desktop

1. Откройте приложение **Claude Desktop**.
2. Перейдите в настройки своего профиля (иконка в углу экрана) и откройте меню: **Settings** → **Developer** → нажмите кнопку **Edit Config**.
3. В открывшемся текстовом файле `claude_desktop_config.json` замените содержимое на следующий JSON-код.

⚠️ **Внимание:** В параметре `"command"` укажите путь к файлу `.exe`, скопированный на Шаге 2. Обязательно **удваивайте** все обратные слэши (`\\`), иначе Claude не сможет запустить сервер!

```json
{
  "mcpServers": {
    "freecad-robust-mcp": {
      "command": "C:\\Users\\Имя_Пользователя\\AppData\\Local\\Programs\\Python\\Python311\\Scripts\\freecad-robust-mcp.exe",
      "args": [],
      "env": {
        "FREECAD_MODE": "xmlrpc",
        "FREECAD_XMLRPC_PORT": "9875"
      }
    }
  }
}
```

4. Сохраните изменения в файле (`Ctrl + S`) и закройте Блокнот.
5. **Полностью перезапустите Claude Desktop**: закройте окно программы, затем кликните правой кнопкой мыши по иконке Claude в системном трее Windows (возле часов) и выберите **Quit**. Запустите приложение снова.

---

## Шаг 4: Проверка работоспособности

1. Запустите FreeCAD и убедитесь, что мост включен (**зеленый индикатор** активен).
2. Откройте Claude Desktop. В строке ввода сообщения (справа внизу) должна появиться **иконка штекера/подключения (Connectors)**.
3. Нажмите на иконку и убедитесь, что сервер `freecad-robust-mcp` находится в статусе «Connected».
4. Отправьте тестовый промпт:
   > *«Создай новый документ во FreeCAD и добавь в него цилиндр радиусом 15 мм и высотой 50 мм»*
5. Перейдите в окно FreeCAD и убедитесь, что объект успешно построился автоматически.

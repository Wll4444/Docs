# 🤖 Концепция: Локальный специализированный AI-агент с Web UI

## 🎯 Идея и Архитектура
Создание предметно-ориентированного агента, запускаемого локально на PC и мобильных устройствах (Android). 

* **Файловая система:** Агент работает с выделенной рабочей директорией: читает подготовленные Markdown/JSON файлы (база знаний, конфиги, контекст) и записывает новые документы по текущим задачам.
* **Бэкенд агента:** Легковесный сервер на Python (FastAPI/LangChain/LlamaIndex) или Node.js.
* **Интерфейс (UI):** Адаптивный Web UI (React, Vue или простой HTML/JS), открываемый в браузере или через WebView на смартфоне.
* **Взаимодействие с LLM:** Абстракция провайдера (поддержка как локальных движков, так и внешних облачных API).

---

## 🛠 Варианты запуска и сложность

### 1. Автономный запуск (Полностью локально)
* **На PC (Сложность: 2/5):** 
  * Движок: Ollama, LM Studio или `llama.cpp`.
  * Модели: 7B–14B (например, Qwen 2.5).
* **На Android (Сложность: 4/5):**
  * Способы: Termux (`llama.cpp` + Python) или нативный клиент (Flutter/React Native) с C-bindings `llama.cpp`.
  * Модели: 1.5B–3B (Quantized Q4_K_M) из-за жестких лимитов RAM и нагрева.

### 2. Гибридный запуск (Локальный агент + Бесплатное Облачное API)
Замена локальной LLM на облачные Free Tiers полностью снимает нагрузку с мобильного устройства и дает доступ к мощным моделям без затрат на аренду GPU-серверов.

* **Google Gemini API (Google AI Studio):**
  * Доступ к Gemini 1.5 Flash / Pro (до 15 RPM бесплатно).
  * Огромное окно контекста (1–2 млн токенов) — отлично подходит для чтения больших папок с Markdown или загрузки 3D-сцен.
  * Нативный и точный Function Calling (JSON-вызовы функций).
* **Groq Cloud API:**
  * Бесплатный доступ к Llama 3.1 (8B/70B), Qwen 2.5, Mixtral.
  * Высочайшая скорость генерации (300–500 токенов/сек).
* **OpenRouter:**
  * Единый ключ к множеству бесплатных моделей (с тегом `:free`).

## 💡 Применимость и Сценарии использования

### 1. Помощник-советчик / RAG по базе знаний (10/10)
* **Суть:** Агент ищет информацию по локальным Markdown-файлам и формирует ответы на их основе.
* **Плюсы:** Легкое обновление базы (просто добавить `.md` файл), отсутствие «галлюцинаций».

### 2. Помощник в 3D-проектировании (Three.js + React) (9/10)
* **Советчик:** Выдача рекомендаций по проектированию на основе инженерной документации.
* **Строительство (Function Calling):** Модель генерирует структурированный JSON (например, `{ action: "add_wall", params: {...} }`), а React-компоненты перехватывают его и вызывают соответствующие функции Three.js / React Three Fiber для сборки 3D-сцены.

### 3. Виртуальная личность / Текстовые ролевые игры (8/10)
* **Суть:** Хранение правил, состояния игрока и мира в локальных `.md` / `.json` файлах.
* **Плюсы:** После каждого хода агент обновляет и перезаписывает файлы сохранения прямо на диске.

## 🚀 Рекомендуемый план разработки

1. **Прототип бэкенда (FastAPI / Node.js):**
   * Реализовать работу с локальными `.md` файлами в директории.
   * Сделать универсальную прослойку (LLM Abstraction): переключение между `http://localhost:11434` (Ollama) и `OpenAI SDK / Gemini API` через `.env`.
2. **Адаптивный Web UI:**
   * Сделать мобильно-ориентированный веб-интерфейс.
3. **Интеграция с предметной областью:**
   * Добавить Function Calling (JSON) для выполнения команд (например, управление Three.js или файлами).
4. **Тесты на мобильном устройстве:**
   * Проверить работу Web UI с телефона через локальную сеть или через Termux при оффлайн-запуске.

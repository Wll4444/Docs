# Практики

Практика — это способ работы, который оправдал себя хотя бы в одном проекте. Здесь для
каждой указано, откуда она взялась и где записан её канонический текст. **Сами правила сюда
не копируются**: копия расходится с оригиналом, как разошлись копии
`/write-stage-report` (четыре версии на пять проектов, сведены в одну 2026-10-01). Самый полный текст большинства правил лежит в
`C:\Projects\Games\Template\CLAUDE.md`, причины — в ретроспективе Golf.

Агент этот файл не правит. Предложение добавить, изменить или отменить практику он кладёт в
[05_Inbox](../05_Inbox/README.md).

## Процесс

| практика | коротко | откуда | канон |
| --- | --- | --- | --- |
| Этап = чат = отчёт = коммит + тег | один этап закрывается одним коммитом с тегом до закрытия чата | Golf: этапы 3–5 ушли одним коммитом, «конец этапа 4» больше нигде не существует | Template `CLAUDE.md` → Process; [ретроспектива Golf](../Projects/Golf/02_Journal/retrospective.md) |
| План — отдельной сессией | до кода; с разделом «чего не будет» (с причиной для каждого пункта) и «что сломается» | Golf | [master_plan_TEMPLATE](../Projects/Template/01_Specs/master_plan_TEMPLATE.md) |
| Реестр долга, правило третьего раза | один реестр; долг, проявившийся трижды, становится целью следующего этапа без обсуждения | Golf | [debt.md Template](../Projects/Template/01_Specs/debt.md) |
| Журнал с оглавлением | `02_Journal/README.md`: таблица этапов вместо пересказа | Golf | [журнал Template](../Projects/Template/02_Journal/README.md) |
| Потолок CLAUDE.md в 200 строк + `<project>-rules.md` | в CLAUDE.md только то, что переживёт смену игры; правила конкретной игры лежат отдельно | Golf, долг D-12: CLAUDE.md дорос до 987 строк | Template `CLAUDE.md`, шапка |
| Последний этап играет человек | его ввод записывается числами | Template, этап C | [playtest.md](../Projects/Template/06_Reference/playtest.md) |
| `/write-stage-report` | отчёт пишется, пока контекст ещё в чате; этап закрывают реестр долга, оглавление журнала, тег и вопрос «есть ли урок для других проектов» → `04_Lessons` | Rubiks-cube → все; одна версия с 2026-10-01 (Inbox от Template) | `~/.claude/commands/write-stage-report.md` — одна на все проекты, вне git. Своё у проекта (папка журнала, реестр долга, имена тегов, потолок CLAUDE.md) команда читает из его `CLAUDE.md`; чего у проекта нет, тот шаг пропускается |
| `/new-prototype` | копия шаблона → новый прототип: переименование, сброс реестров, план | Golf, Template, Nature (три разные версии) | `Template/.claude/commands/new-prototype.md` |

## Измерения

| практика | коротко | откуда | канон |
| --- | --- | --- | --- |
| Скриншот-харнесс | `npm run shot`: настоящая игра в настоящем браузере без окна; PNG надо смотреть глазами | Darts | [screenshot-harness.md](../Projects/Template/06_Reference/screenshot-harness.md) |
| Калибровка `--table --check` | число живёт в `calibration.json`, проверка перемеряет заново против закоммиченной записи | Golf, этап H2 | [calibration.md](../Projects/Template/06_Reference/calibration.md) |
| Проверка проверяется поломкой | мутация того, что проверка сторожит, должна сделать её красной | Template: харнесс A, debt-05 | `scripts/mutate.mjs` Template, Template `CLAUDE.md` → Measuring |
| Diff как число и место | сколько пикселей изменилось и **где** | Nature, этап 3 → Template `harness-d` | `scripts/diff.mjs` Template (`npm run diff`) |
| «Измерено» — свойство кода и сцены | всё унаследованное (уровни качества, AO, bloom, калибровка) перемеряется в новой сцене | Golf: AO съедал 62% кадра ради 0.08% пикселей | Template `CLAUDE.md` → Measuring |

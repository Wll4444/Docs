# Nature

Это не игра, а песочница для рельефа, биомов и растительности. В ней один участок
процедурной земли, зонд, который можно на него бросить, четыре вида камеры и полный
измерительный харнесс, унаследованный от Golf. На выходе получаются переиспользуемые и
**измеренные** куски (функции высот, поля биомов, рассадка, инстансная растительность) и
знание о том, сколько они стоят. Предназначены они для прототипов, которым нужен ландшафт.

**Статус:** этап 4 закрыт: трава тайлами вокруг глаза, прореживание с расстоянием, заглушка
ветра. Затем П-3 (2026-09-30): исправления харнесса из Template перенесены (строка `--table`
судится тем же `runErrors`, что и ручной прогон; запись только из всего манифеста). П-2
(2026-10-01): скан точек и поз стал командой `npm run scan` (долг D-08 закрыт), тесты зовут его
вердикты, найдена точка зонда на лугу. П-4 (2026-10-01): звуки в записи датированы шагом
физики своего броска (долг D-10 закрыт), затык страницы стал флагом `--stall`. Этап 4b
(2026-10-01): ветер — поле `(x, z, t)` с порывами, по нему гнутся трава и деревья вместе с
тенями; копия в GLSL сверяется с JS на GPU; цена — в бюджете +0.5 мс. Живой прогон автором —
«выглядит очень здорово». П-5 (2026-10-06): ветер слышен — петля розового шума, уровень и
фильтр от поля у глаза камеры; харнесс пишет её уровень строкой `ambient:` и теперь падает на
любом `SILENT` и на контексте не в `running` (урок Template). Живой прогон автором — «хорошо получилось», настройки по умолчанию.
Этап 5 (2026-10-07): тени — два каскада, подогнанные к камере, и тень рельефа (долги D-05,
D-06 закрыты); у вида с земли до этого не было теней на переднем плане. Цена +0.70 мс при
бюджете +1.5; третий каскад не влез — проход с деревьями стоит ~1 мс по причине, которая не
найдена (D-17). П-6 (2026-10-08): частота GPU в приборе (долг D-01 закрыт) — `nvidia-smi` рядом с
каждым прогоном, цена A/B по ровным парам, частота в записи, цены и время GPU впервые сверяются;
драйвер держал «простаивающую» карту на ступенях частоты, и цена оказалась свойством ступени
([урок](../04_Lessons/2026-10-08-nature-gpu-time-belongs-to-a-clock-step.md)). Этап 5b (2026-10-15):
затемнение запечено в вершину растения и в карту под растениями, гасит только рассеянный свет —
11–16% пикселей за ~0 мс; N8AO (+2 мс) и блум (0 пикселей за +1.1 мс) не входят, MSAA 4× остаётся
по живому прогону ([урок](../04_Lessons/2026-10-08-tinywhoop-post-effect-weighed-by-pixels-it-changes.md),
подтверждение). Первая сверка между сессиями не прошла: настройка драйвера перестала держать
ступень частоты — D-01 открыт снова, следующий этап П-7. С 2026-10-08 Nature в пилоте Codex-ревью ([протокол](../00_Reference/codex-review-workflow.md)): первое ревью — проекта целиком на `95af829`, дальше по этапам с 5b (`AGENTS.md` проекта). ## Что можно взять

- **Heightfield**: [heightfield.md](../Projects/Nature/06_Reference/heightfield.md).
- **Биомы, рассадку, траву** вместе с ценой каждого шага:
  [этап 2](../Projects/Nature/02_Journal/stage-02-biomes.md),
  [этап 3](../Projects/Nature/02_Journal/stage-03-vegetation-scatter.md),
  [этап 4](../Projects/Nature/02_Journal/stage-04-grass.md).
- **`scripts/diff.mjs`**: какая доля пикселей изменилась между двумя скриншотами и **где**
  именно. Перенесён в Template (`harness-d`, 2026-09-30) — брать оттуда.
- **Скан «где может стоять прибор»** (`npm run scan`, П-2): критерии точек и поз камеры как
  данные, вердикты общие с тестами, поиск по ним. Для наследника с камерой, выбранной по
  рельефу: [отчёт П-2](../Projects/Nature/02_Journal/stage-p2-scan.md). Запускает TypeScript
  из `src/` через `runnerImport` Vite, без нового пакета.
- **Поле ветра** (этап 4b): `getWind(x, z, t)` из дорожной карты — чистая функция с порывами,
  сносимыми ветром, без знания рельефа; её копия в GLSL на целочисленном хеше, сверка копий на
  GPU (`--scenario=wind`) и качание растений с тенью. Для Облаков (#20) и Буера (#21):
  [отчёт этапа 4b](../Projects/Nature/02_Journal/stage-04b-wind.md).
- **Звук ветра** (П-5): петля синтезированного розового шума с бесшовным переходом,
  голос как чистая функция скорости ветра (`windVoice`), привязка по кадру к полю у глаза,
  проверка петли харнессом (запрошенное в записи, RMS выхода — вердикт без записи). Для
  Облаков (#20) вместе с полем: [отчёт П-5](../Projects/Nature/02_Journal/stage-p5-wind-sound.md).
- **Каскадные тени без аддона CSM** (этап 5): каскады, подогнанные к камере (чистые функции с
  тестами), и одна вставка в шейдер, которую проходит каждый материал с `onBeforeCompile`;
  харнесс проверяет порядок каскадов на GPU. Для Golf (тени деревьев вдоль фервея, этап 8) и
  любого наследника с лесом: [отчёт этапа 5](../Projects/Nature/02_Journal/stage-05-shadows.md).
- **Время события — шаг физики** (П-4): удар несёт номер шага своего броска, запись сверяет
  шаги точно, `--stall=ms` показывает, что затык страницы число не двигает. Новее, чем в
  Template и Golf: [отчёт П-4](../Projects/Nature/02_Journal/stage-p4-sound-steps.md).
- **Частота GPU рядом с замером** (П-6): `scripts/gpuClock.mjs` — семплер `nvidia-smi`, частота
  к каждому окну, цена парного A/B только по ровным парам, проверка свободного GPU до прогона.
  Для любого проекта, который пишет время GPU в запись: [отчёт П-6](../Projects/Nature/02_Journal/stage-p6-gpu-clock.md);
  предложение о переносе в Template — в Inbox.

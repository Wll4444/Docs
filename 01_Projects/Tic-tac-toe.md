# Tic-tac-toe

Крестики-нолики на кубе 3×3×3 (27 ячеек): победа по любой из 49 линий (ортогональным,
плоским и пространственным диагоналям), подсветка выигрышной линии, табло X / O / ничьи,
камера с ограничениями.

# Перенести в харнесс Template чтение частоты GPU рядом с прогоном и судью пар A/B по частоте

**Почему.** В Nature время GPU и парные A/B не воспроизводились между прогонами, и причиной
оказались ступени частоты, которые драйвер выбирает для слабо загруженной карты; цена — свойство
ступени, не пропорционально частоте
([урок](../04_Lessons/2026-10-08-nature-gpu-time-belongs-to-a-clock-step.md), числа —
`Nature/Docs/06_Reference/performance.md`, «Частота GPU»). Любой наследник Template, который меряет
время GPU, получит ту же ловушку.

**Что именно сделать.** Из Nature (коммит этапа П-6, тег `stage-p6`):
- `scripts/gpuClock.mjs` и `scripts/gpuClock.test.mjs` — семплер `nvidia-smi` рядом с прогоном,
  `clockOver` (частота за окно), `judgeByClock` (цена только по ровным парам), `utilisationNow`
  (GPU свободен до прогона). Без `nvidia-smi` молча отсутствует.
- В `src/dev/perf.ts` и `PerfProbe.tsx` — счётчик выброшенных запросов таймера (`disjoint` /
  `aged`), иначе отрезок без GPU-времени неотличим от страницы, которая ничего не рисовала.
- В отрезке A/B (`e2e.ts`, `paired`) — границы окна в `Date.now`, чтобы драйвер мог пришить частоту.
- В записи калибровки — частота рядом с ценой (`abClockMHz` точно, `priceMs` с допуском из разброса).

Если у Template парного A/B нет — переносится только семплер с частотой в строке `gpu:` и проверка
свободного GPU.

**Чем рискуем, если не сделать.** Наследник снова два этапа будет объяснять разброс «частотой»,
не прочитав её, и заводить `tol: null` на всё, что меряет GPU.

## Дополнение (2026-10-22, Nature, этап П-7)

Если переносить — переносить вместе с тем, что добавил П-7 (тот же файл и `shot.mjs`):
- `heldStep` и `idleHeld` в `gpuClock.mjs` (с тестами): ступень проверяется **до** таблицы — сцена A/B
  ставится и 3 с стоит под семплером; отсчёт с «GPU idle» (`0x1`) или, под `--check`, частота, на
  которой не мерилась ни одна цена записи, — отказ с причиной за ~10 с. Отсчёт «GPU idle» внутри
  любого окна валит прогон и останавливает таблицу (`clockLost` в `shot.mjs`). Нужно потому, что
  настройка драйвера, державшая ступень, перестала действовать без видимой причины и вернулась
  только перезагрузкой ([урок](../04_Lessons/2026-10-08-nature-gpu-time-belongs-to-a-clock-step.md), подтверждение 2026-10-22).
- Закреплённый браузер замеров: Playwright запускает свой Chromium (`channel: 'chromium'`, не headless shell — у него не крутится цикл кадров), `playwright-core` в `package.json` — точной версией, `npm run browser` его ставит, версия — в `machine.browser` записи и сверяется `--check`. Системный Chrome обновляется сам раз в несколько дней.

# Node-скрипт может импортировать TypeScript игры через `runnerImport` из Vite — без tsx и vite-node

**Что было.** Скану точек в Nature нужны чистые функции из `src/world/*.ts` в Node-скрипте.
Node 22 сам снимает типы только с файлов, где импорты указаны с расширениями, а `tsx` и
`vite-node` в проекте не было, и новый пакет — отдельное решение. В Vite 8, который уже стоит,
есть `runnerImport(path, { root, configFile: false })`: он прогоняет модуль через тот же
конвейер, что dev-сервер, и отдаёт его экспорты. Первый импорт занимает около 0.2 с. Сделано в
`Nature/scripts/scan.mjs`.

**Почему важно другим.** Харнессы Golf и Template держат в `.mjs` логику, которая дублирует
TypeScript игры или читает её через страницу в браузере. Где нужна чистая функция (рельеф,
правила, конфиг), её можно звать напрямую из скрипта, и тогда она одна, а не две.

**Как применить.**
- `import { runnerImport } from 'vite'`;
  `const { module } = await runnerImport('/src/…/x.ts', { root, configFile: false, logLevel: 'error' })`.
- `configFile: false`, чтобы не тянуть плагины dev-сервера, если они не нужны модулю.
- Логику держать в `.ts` (там её видят линтер и `tsc`), а в `.mjs` оставлять только флаги и
  печать.

# Исправление в копии общего кода до соседей не доходит, и они открывают его заново — ценой неверного замера

**Что было.** Сверка `shot.mjs` трёх проектов нашла один и тот же дефект, исправленный
дважды и независимо. Если порт 5173 занят чужим проектом, харнесс снимает чужое приложение
как своё. Nature закрыл это на своём этапе 0 (`153fe87`, 2026-09-25, проверка по `<title>`).
Template открыл тот же дефект заново через три дня, уже **после** замера чужой сцены
(`7216650`, 2026-09-28; треугольники чужой сцены записаны в комментарии к
`servesThisProject` в `Template/scripts/shot.mjs`). Golf не закрыл его до сих пор
(`Golf/scripts/shot.mjs`, `startServer`). Второй случай — противоположный. Template 28.09
записал в долг T-10 лекарство «таймер GPU», а Nature построил его на следующий день
(`e3d61f9`), и ни один проект не знал о другом. Полный список «есть только в одном» —
`Template/Docs/01_Specs/harness_reconcile_plan.md`, §2.

**Почему важно другим.** Правило «обратный перенос через Inbox» (`06_Code`, правило 3)
работает, только если тот, кто чинит общий код, считает свою правку общей. Защита от
чужого сервера и таймер GPU такими не показались: их сделали по ходу предметного этапа.
И ещё одна находка. Во всех трёх драйверах `--quality` и `--lang` кладутся в URL и не
читаются обратно (Template T-18): правило «флаг проверяет себя» соблюдено для тех флагов,
которые уже раз подвели, и только для них.

**Как применить.**
- В Golf: драйвер на 5173 снимет любой проект, который там запущен. Перед следующим
  `npm run shot` добавьте проверку, чей это сервер (варианты — Template по `package.json`,
  Nature по `<title>`).
- Правку в `scripts/` или `src/dev/` любого проекта проверяйте вопросом «это про мою игру
  или про прибор?». Если про прибор — положите строку в `05_Inbox` с `kind: code`, даже
  когда правка сделана по ходу другого этапа.
- Перед тем как чинить харнесс, прогоните grep по той же функции у соседей. С сервером на
  5173 решение к тому времени уже три дня было в соседнем проекте.

## Подтверждения

- 2026-09-30, Template, этап `harness-d` (после коммита `58c86f1`) — третий случай, и уже
  не из-за того, что правку не сочли общей. Ограничение перенесённого прибора лежало в
  **журнале** соседа, а не в его коде. Таймер GPU Nature работает только с vsync, без него
  отвечает на единицы кадров из сотен (`Nature/Docs/02_Journal/stage-03-vegetation-scatter.md`).
  В коде Nature об этом ни строки, а сверка читала код — и план Template назначил замеру команду с
  `--novsync`, под которой прибор молчит. Переоткрыто за полчаса отладки
  (`Template/Docs/02_Journal/stage-hd-setting-cost.md`, находка 1). **Применить:** перенося
  прибор из соседа, прочитать журнал этапа, который его построил, а не только файл.
